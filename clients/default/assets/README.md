# Default client assets

This directory is reserved for client-specific branding assets.

Required production source artwork:

- `app-icon.png`: 1024 x 1024 opaque sRGB PNG.
- `splash-logo.png`: at least 1200 x 1200 transparent PNG.
- `brand-logo.png`: at least 512 px wide transparent PNG.

Preparation generates Android, iOS, and runtime assets automatically. Development uses generic placeholders while all three files are absent. Production requires all three valid files. Do not edit generated outputs.
