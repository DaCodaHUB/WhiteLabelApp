# Demo client assets

This directory is reserved for client-specific branding assets.

Optional demo source artwork (development generates generic placeholders while all three files are absent):

- `app-icon.png`: 1024 x 1024 opaque sRGB PNG.
- `splash-logo.png`: at least 1200 x 1200 transparent PNG.
- `brand-logo.png`: at least 512 px wide transparent PNG.

Preparation generates Android, iOS, and runtime assets automatically. If you add any source artwork, add all three valid files. Do not edit generated outputs.
